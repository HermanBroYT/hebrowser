# HerLinux 2

Рабочий стол в стиле Windows для Android. Это приложение-оболочка поверх Android, а не отдельная операционная система.

**Версия:** 2.1 · **Android:** 8.0 и выше · **Файл:** `HerLinux-2.1.apk`

## Возможности

- Рабочий стол с обоями, значками «Компьютер» и «Корзина».
- Панель задач: кнопка «H», проводник, браузер, терминал, громкость, экран, батарея, часы и дата.
- Меню «Пуск»: Настройки, Командной строки, Параметры экрана, Программы, Проводник, Браузер, Блокнот, Калькулятор, «Завершить работу», «Перезапуск».
- Окна: перетаскивание, сворачивание, закрытие, анимации.
- Запуск как в Windows: значок и название HerLinux, полоса загрузки (случайно 10–25 секунд), экран «Добро пожаловать».

### Настройки
| Раздел | Что внутри |
|---|---|
| Подключения | состояние сети, быстрый переход в Wi-Fi, Bluetooth, мобильную сеть, режим полёта |
| Оформление | три цветовые схемы, включение и выключение анимаций |
| Дата и время | часовой пояс, формат часов 12/24 |
| Экран | разрешение, плотность, частота обновления, яркость внутри HerLinux |
| Память | реальный объём хранилища и ОЗУ, размер диска HerLinux, корзина, доступ ко всем файлам |
| О программе | версия, устройство, Android, процессор |

### Проводник
- «Этот компьютер»: диск HerLinux, внутренняя память, карта памяти, корзина, быстрые папки; для дисков показаны объём и заполнение.
- Открытие любых папок телефона (после выдачи доступа ко всем файлам).
- Создание папок и файлов, корзина, восстановление, свойства файла.
- Открытие файлов: текст идёт в «Блокнот», `.apk` — в установщик, остальное — в подходящее приложение.

### Программы
- Окно «Программы» показывает установленные Android-приложения: нажатие запускает, долгое нажатие удаляет.
- Установка: откройте файл `.apk` в проводнике или командой `install файл.apk`.
- Windows-программы (`.exe`) на Android не запускаются: нужен эмулятор, например Winlator. HerLinux покажет пояснение и предложит открыть файл в другом приложении.

### Командная строка
Работают команды Linux и Windows.

| Группа | Команды |
|---|---|
| Файлы | `ls`/`dir`, `cd`, `pwd`, `mkdir`/`md`, `rmdir`/`rd`, `touch`, `cat`/`type`, `rm`/`del`, `cp`/`copy`, `mv`/`move`/`ren`, `tree`, `head`, `wc`, `grep` |
| Текст | `echo текст`, `echo текст > файл`, `echo текст >> файл` |
| Система | `date`, `time`, `whoami`, `hostname`, `uname`, `ver`, `neofetch`/`systeminfo`, `df`, `free`, `uptime`, `ps`/`tasklist` |
| Сеть | `ping`, `ipconfig`/`ifconfig` |
| Прочее | `start`/`open`, `install`, `apps`, `history`, `clear`/`cls`, `exit` |

Диск `C:` — это диск HerLinux, `D:` — внутренняя память. Пути с пробелами пишите в кавычках. Кнопки ▲ и ▼ листают историю команд.

## Установка

1. Скачайте `HerLinux-2.1.apk`.
2. Разрешите установку из неизвестных источников.
3. Откройте файл и установите.
4. Чтобы HerLinux стал главным экраном: Настройки Android → Приложения по умолчанию → Главное приложение.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Интернет | браузер |
| Состояние сети | раздел «Подключения» |
| Доступ ко всем файлам | открытие всех папок телефона |
| Установка приложений | установка `.apk` |
| Удаление приложений | удаление из окна «Программы» |

Доступ ко всем файлам включается при первом открытии «Внутренней памяти» или в Настройки → Память. На Android 10 доступ к внутренней памяти может быть ограничен системой.

## Сборка через GitHub

1. Загрузите проект в репозиторий GitHub.
2. Откройте **Actions → Android → Run workflow**.
3. Через несколько минут скачайте `HerLinux-2.1` из раздела **Artifacts**.

Нужны JDK 17 и Gradle 8.7; в Actions они подключаются автоматически.

## Ограничения

- Это оболочка поверх Android: свои программы, драйверы и ядро не заменяются.
- Файлы `.exe` не запускаются без внешнего эмулятора.
- Браузер ищет через Яндекс.
